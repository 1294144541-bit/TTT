# TTT 增强世界模型：产业进展、物理尺度预测与智能驾驶落地评测方案

## 1. 产业界最新进展与具身/世界模型技术图谱

当前具身智能与自动驾驶头部企业正在经历从“静态自回归视频生成”向“具备物理交互性与空间智能的世界模型”转折。但在面对物理动力学实时漂移时，业界目前的方法仍存在结构性缺陷：

### 1.1 头部企业技术路线剖析
1. **Wayve (GAIA-2 / GAIA-3 系列)**
   - **架构**：自回归与扩散混合架构（Video Generative World Models），输入历史驾驶视频序列与控制指令（Steering / Acceleration），生成未来长时序多视角驾驶场景。
   - **痛点**：属于开环/离散想象器，生成侧重于高保真像素纹理，缺乏底层物理刚度与摩擦学约束；当车辆行驶至未见过的低附着系数路面（如泥泞或黑冰）时，生成画面易产生“物理幻觉”（如轮胎不打滑但车身瞬移），无法在线自我校正物理参数。
2. **Tesla (FSD 端到端与世界模型仿真)**
   - **架构**：以视觉主导的高帧率感知-决策大模型（36Hz 高频推理回路），在仿真端使用基于神经渲染与时空预测的世界模型（World Model Simulator）生成长尾长距离工况。
   - **痛点**：部署在车端工控芯片上的神经网络权重在推理期完全静态冻结。在遭遇连续强侧风扰动、悬挂老化或载重突增等工况时，完全依赖长序列历史缓存（KV-Cache / Recurrent Tokens）隐式估计惯性参数，计算与显存占用随推理交互时程增加。
3. **World Labs (Fei-Fei Li / Spatial Intelligence)**
   - **架构**：聚焦空间智能（Spatial Intelligence），从单张图片或短序列生成三维交互式几何世界模型（如 Atlas 架构）。
   - **痛点**：强调三维几何（3D Geometry）与物体形变的静态先验重建，而非闭环具身行动下的瞬态牛顿力学（Newtonian Dynamics）反向校准。
4. **Physical Intelligence (π0 / Generalist Robot Policies)**
   - **架构**：基于 Flow Matching / Diffusion 的 Vision-Language-Action (VLA) 多任务操作模型。
   - **痛点**：依赖百亿级别跨本体交互轨迹数据预训练，当机械臂抓取未知惯性矩物体（如半满液体杯）或遭遇地面摩擦力突变时，策略网络内部无流式自校准机制，容易因动态延迟与模型失配导致抓取抖动或失稳。

## 2. 任务一：世界模型物理尺度预测能力评测方案

### 2.1 任务目标与评测定义
验证在**无真值物理参数输入**的前提下，TTT 增强的世界模型能否通过视觉观测序列的动力学误差流，在线推导出真实物理参量（如质量、摩擦系数、弹性恢复系数、重力加速度常数），并在隐空间维持严格的动力学守恒。

### 2.2 数据选型与可得性/训练难度评估

| 数据源类型 | 具体数据集 / 平台 | 数据可得性 | 训练与工程难度 | 适用性与针对评测场景 |
| :--- | :--- | :--- | :--- | :--- |
| **可控合成物理模拟 (推荐主力基准)** | **Physion / CLEVRER / IntPhys**<br>(包含刚体碰撞、滚动摩擦、浮力等扰动) | **高** (完全开源，MIT 协议，包含精准 Ground Truth 物理参数与标注) | **低至中**<br>(可直接获取 RGB 视频 + 物体 3D 轨迹 + 碰撞物理属性标签) | **评测目标**：验证因果推理与质量/摩擦力估算。<br>输入：物体推挤/滑动视频片段；<br>检验指标：$W_t$ 在线梯度更新后对后续物体运动距离与反弹速度预测的准确度。 |
| **可微/参数可调物理引擎** | **Brax / Isaac Gym (Orbit) Non-Stationary Suite** | **极高** (本地 GPU 脚本可批量合成百万级参数渐变轨迹) | **低**<br>(MuJoCo / Isaac 官方支持在线修改刚体物理参数 `friction`, `mass`, `damping`) | **评测目标**：连续参数漂移（如刚体质量随时间按正弦曲线 $\xi_t = m_0(1 + 0.5\sin(\omega t))$ 变化）。<br>检验隐层权重 $W_t$ 的变化轨迹是否与真实物理参量演化流形保持同构。 |
| **真实物体物理交互机器人数据集** | **BridgeData V2 / DROID / RT-X** (包含吸盘、夹爪与物体滑动交互) | **高** (Hugging Face / Google Storage 开放下载) | **高**<br>(视觉视角多样、存在杂乱遮挡、需抽取机器人本体末端位姿与接触力) | **评测目标**：真实世界接触与形变下的物理尺度泛化。检验抓取不同刚度/质量物体时，潜空间残差反向传播能否在 3~5 帧内消除穿模与误判。 |

### 2.3 物理尺度评测指标设计
1. **参数可解释映射一致性 (Parameter Decodability Metric, $R^2$)**：
   在冻结特征提取器的前提下，从适配后的参数矩阵 $W_t$ 训练一个微型线性探测器（Linear Probe）预测真实物理参数 $\xi_t$（如质量 $m$ 或摩擦系数 $\mu$），计算决定系数 $R^2$：
   $$R^2 = 1 - \frac{\sum_t (\xi_t - \text{Probe}(W_t))^2}{\sum_t (\xi_t - \bar{\xi})^2}$$
   若 $R^2 > 0.85$，证明流式梯度成功将动力学误差编码进了权重拓扑中。
2. **长程时空穿模与能量漂移率 (Hamiltonian Energy Violation, HEV)**：
   计算预测未来 $H$ 步的隐空间广义动能/势能与物理动量守恒偏离度：
   $$\text{HEV} = \frac{1}{H}\sum_{\tau=1}^H \max\left(0, \mathcal{H}(\hat{z}_{t+\tau}) - \mathcal{H}(\hat{z}_{t+\tau-1}) - \mathcal{P}_{\text{ext}}\right)$$
3. **外推物理预测误差 (Out-of-Distribution Rollout L2 Error)**：
   在未见过的极端物理参数（如重力变更为 0.5g 或 2.0g）下，对比测试期冻结权重的 DreamerV3 / TD-MPC2 与 TTT 增强模型的预测位移均方误差（MSE）。

## 3. 任务二：纯视觉智能驾驶世界模型应用评测方案

### 3.1 任务目标与评测定义
在纯视觉（Camera-only）端到端自动驾驶场景中，车辆仅凭借多视角环视相机（Surround-view Cameras）输入，利用世界模型进行前向未来场景预测与自车轨迹规划。当遭遇路面结冰、突降暴雨轮胎打滑、严重载重失衡等**动力学非平稳突变**时，评测 TTT 能否利用连续帧自监督重构/特征预测残差，在线更新自车运动学转移核，避免自车因规划失配而发生碰撞。

### 3.2 数据选型与可得性/训练难度评估

| 数据源类型 | 具体数据集 | 数据可得性 | 训练与工程难度 | 适用性与针对评测场景 |
| :--- | :--- | :--- | :--- | :--- |
| **真实自动驾驶多视角视频基准** | **nuScenes / Waymo Open Dataset (WOD)** | **高** (学术界标配，提供环视多相机视频、LiDAR、自车 IMU/CAN 动力学总线数据) | **中**<br>(数据规整，提供标定的相机内外国参和车辆里程计) | **评测目标**：开环未来点云/隐空间特征预测。<br>在常规工况预训练基础世界模型，在恶劣天气或夜间低能见度工况（Rain/Night splits）执行 TTT 在线流式推理测试。 |
| **交互式闭环规划仿真平台 (核心推荐)** | **CARLA 0.9.15 (带动力学扰动插件)** 或 **nuPlan Closed-Loop Simulator** | **极高** (开源仿真器，可直接控制仿真底层物理引擎 PhysX) | **中至高**<br>(需要搭建闭环控制桥接脚本，如 Python API 绑定) | **评测目标**：闭环碰撞率与打滑控制。<br>在车辆行驶中动态注入路面摩擦系数骤降（$1.0 \to 0.2$）或载重剧变，评测 TTT-MPC 规划器在多步想象中是否能即时抑制刹车距离低估。 |
| **极端天气与事故长尾驾驶视频** | **DADA-2000 / DeepAccident / A2D2** | **中** (需申请或批量下载特定长尾标注数据) | **高**<br>(真实事故数据帧率不均，往往缺少完整的 CAN 总线底盘控制量) | **评测目标**：评估碰撞临界瞬间前向误差信号激增时，TTT 权重的抗抖动性与收敛速度。 |

### 3.3 智驾场景核心评测维度与指标

1. **时空运动预测因果误差 (Kinematic Trajectory Prediction Error)**：
   在模型预测控制（MPC）中，评估未来 1~3 秒（$H=10 \sim 30$ 步）的预测轨迹点与真实车辆物理轨迹的平均位移误差（ADE, Average Displacement Error）与终点位移误差（FDE, Final Displacement Error）：
   $$\text{ADE} = \frac{1}{H} \sum_{\tau=1}^H \|\hat{p}_{t+\tau} - p_{t+\tau}\|_2$$
2. **闭环安全接管率与碰撞率 (Intervention & Collision Rate)**：
   在 CARLA 闭环测试集中，统计在遭遇非平稳地面扰动工况下每 100 公里的临界接管次数（Disengagements per 100km）以及自车越界/碰撞百分比。
3. **自适应延迟与硬件推演频率 (Real-Time Latency & Compute Throughput)**：
   - **更新关键路径延迟**：测试期单次前向 + 梯度回传投影 $\widetilde{G}_t = P_\perp G_t$ + 权重更新 $W_{t+1}$ 的总体耗时（以 NVIDIA Orin / RTX 4090 为基准，需达 $\le 25\text{ms}$，满足 40Hz 实时闭环）。
   - **显存稳定性**：验证在持续 20 分钟以上（数万步流式推理）的长程运行中，GPU 显存占用是否严格维持在常数 $O(1)$，无显存泄漏或回放缓存溢出。

## 4. 推荐落地实施路线（Roadmap）

1. **Phase 1: 物理可控仿真验证（1~2 周）**
   - 依托 **Brax / Isaac Gym** 搭建非平稳动力学环境（注入变摩擦/变质量扰动）；
   - 在低维状态或隐空间中实现 TTT-Linear 残差更新动力学，对比纯 RNN（Dreamer）与静态 Transformer（IRIS）的长程泛化误差。
2. **Phase 2: 纯视觉视频与空间智能预测（2~3 周）**
   - 使用 **Physion** 或 **CLEVRER** 视频数据集，输入纯视频特征（利用冻结的 V-JEPA 或 DINOv2 作为编码器 $E_\phi$）；
   - 构建逆动力学因果损失 $\mathcal{L}_{\text{inv}}$ 与前向残差损失 $\mathcal{L}_{\text{forward}}$，测试物理属性（质量/速度）的解耦探测性能。
3. **Phase 3: CARLA 纯视觉闭环智能驾驶评测（3~4 周）**
   - 搭建 CARLA 环视纯视觉世界模型，使用快慢双回路（Fast-Planning @ 50Hz, Slow-TTT @ 20Hz）完成闭环 MPC 控制验证；
   - 形成具有顶会（NeurIPS / ICLR / CVPR）竞争力的完整实证数据支撑。
