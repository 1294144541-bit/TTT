## 一、 核心痛点与立项动机（Why this problem?）

### 1. 产业界与学术界主流世界模型的致命瓶颈
- **痛点一：静态权重失配（Static Weights Mismatch）**  
  主流世界模型（如基于 Transformer 的 [IRIS](https://arxiv.org/abs/2209.00588)、[TransDreamer](https://arxiv.org/abs/2202.09481)，或基于 RSSM 的 [DreamerV3](https://arxiv.org/abs/2301.04104)）在部署时权重**严格冻结**。当环境物理动力学发生分布外漂移（OOD Drift，例如路面突发结冰打滑、机体载重增加 200%、机械臂抓取未知粗糙度物体）时，出厂模型必然产生物理失配。
- **痛点二：长上下文 KV-Cache 的显存膨胀与自吞噬发散**  
  依赖长上下文 Transformer 隐式猜测参数（In-Context Learning）在工程上存在两大死穴：
  1. **显存随步数线性爆炸 $O(T \cdot d)$**，无法在车载芯片或机器人端侧长时间运行；
  2. **自回归自吞噬发散（Autoregressive Self-Cannibalization）**：在开环推演时，前面自生成的带幻觉 Token 塞入 KV-Cache 作为历史上下文，导致后续推演产生指数级雪崩。

### 2. 我们的核心科学假设（Our Hypothesis）
**打破“冻结权重 + 依赖长上下文 KV-Cache 隐式猜测参数”的范式，将世界模型面对动力学漂移时的预测误差，转化为流式自监督梯度信号，直接在线修正局部可塑权重的几何流形（In-Weights Adaptation），以常数 $O(1)$ 显存实现长程鲁棒的自适应推演。**

## 二、 系统架构与工作逻辑（How it works?）

我们构建了一套**双闭环协同架构（Dual-Loop Bayesian In-Weights World Model）**：

```
                       [224x224 原始多帧相机视频]
                                   │
                                   ▼
          ┌────────────────────────────────────────────────────────┐
          │ 1. 视觉感知骨干 (Meta 官方开源 V-JEPA 2.1 ViT-B/16, 85.65M)│
          │    - 提取 768 维时空 Token 嵌入，测试期严格截断梯度 sg[·] │
          └────────────────────────┬───────────────────────────────┘
                                   │
                                   ▼
          ┌────────────────────────────────────────────────────────┐
          │ 2. 差分物理动力学颈 (Dynamics Velocity Projector)        │
          │    - 状态差分: s_t = Projector(z_t, Δz_t), Δz_t = z_t - z_{t-1}│
          │    - 作用: 滤除大模型静态语义不变性，恢复加速度与接触冲量 │
          └────────────────────────┬───────────────────────────────┘
                                   │
                                   ▼
          ┌────────────────────────────────────────────────────────┐
          │ 3. 动力学混合推演层 (Hybrid Latent Dynamics)           │
          │    \hat{s}_{t+1} = f_θ(s_t) + K_t · (W_t^T x_t)        │
          │    - 不变核心 f_θ: 固化通用物理先验 (离线预训练后冻结)   │
          │    - 局部可塑层 W_t: 接收流式梯度在线更新 (捕获时变物理) │
          │    - 贝叶斯增益 K_t: 动态置信度分配 (防止开环发散)      │
          └────────────────────────┬───────────────────────────────┘
                                   │
                    ┌──────────────┴──────────────┐
                    │ 实时真实反馈 s_{t+1} 到达    │
                    ▼                             ▼
       ┌───────────────────────────┐ ┌───────────────────────────┐
       │ 内环: 参数空间 TTT 梯度流  │ │ 外环: 逻辑空间 贝叶斯滤波 │
       │ - 零空间投影 P_⊥ 保护基底 │ │ - 评估新息残差动态调整 K_t│

       └───────────────────────────┘ └───────────────────────────┘
```

1. **结构正交解耦（Null-Space Projection $P_\perp$）**：
   利用离线特征协方差进行 SVD 分解，构建 $P_\perp = I - U_{\text{core}} U_{\text{core}}^\top$。流式梯度严格投影在扰动变化子空间上（$U_{\text{core}}^\top \widetilde{G}_t \equiv 0$），从数学结构上免疫对通用物理规律的灾难性遗忘。
2. **Ornstein-Uhlenbeck (OU) 参数漂移有界性**：
   引入近端回拉力 $-\beta(W_t - W_0)$，保证即使面对极端测试环境持续更新，内部权重模长在长时间极限下恒定有界。
3. **贝叶斯逻辑自适应门控（Bayesian State Confidence Gate）**：
   在系统决策外环通过卡尔曼增益比对环境反馈，结合速度耗散门控 $\tanh(\alpha \|\Delta s\|)$，在物体停止时平滑将残差收敛归零，解决长程自回归推演中的“过补偿发散”。

## 三、 全流程工程落地与实测演进脉络（Evolution & Milestones）

我们的实验并非单一跑分，而是经历了**由浅入深、层层暴露矛盾并攻坚解决**的严谨演进过程：

### 阶段 1：质点动力学理论原型与自洽性验证
- **实现**：编写了二阶连续刚体动力学环境，验证了 $P_\perp$ 投影算子与在线 SGD 在低维数值空间的可行性；
- **发现**：证实了流式梯度能够将环境物理误差反向编码入权重。

### 阶段 2：Meta 官方 V-JEPA 2.1 真实底座加载与语义坍塌攻坚
- **实现**：在本地环境配置全套生态，加载官方 **ViT-B/16 (419MB, 85.65M 参数)** 权重；
- **暴露深层矛盾**：直接套用 V-JEPA 表征时，物理参数解耦度极低（$R^2 \approx 0.03$）。原因在于大模型的高层表征具备强“语义不变性”，在平缓运动下会平滑掉瞬时微观加速度；
- **解决机制**：创新设计了**差分物理投影头（Delta-Projector: $\Delta z_t = z_t - z_{t-1}$）**，成功激活了 V-JEPA 的牛顿力学感知能力，摩擦力解耦度从 $0.03$ 跃升至 **$R^2 = 0.7082$**（提升超 20 倍）。

### 阶段 3：长程开环自回归推演与“过补偿陷阱”的发现与解决
- **暴露深层矛盾**：在未来多步自回归开环推演中，纯线性 TTT-Linear 会在滑动末期持续注入恒定减速残差，引发过补偿发散；
- **解决机制**：引入外环贝叶斯卡尔曼增益与动能耗散门控（Bayesian-TTT），将长程开环推演累积误差压回稳定包络线。

### 阶段 4：真实实拍 200 帧长视频与全量强基准（Strong Baselines）对标
- **实现**：载入 200 帧真实自然实拍视频，并构建了带 16 步滑动 KV-Cache 的**因果 Transformer 世界模型**以及**开放全网权重的在线微调模型**进行同台对标。

- **TTT 梯度反传与投影更新耗时**：$0.054 \text{ ms}$

- **全链路单步更新总耗时**：**$0.056 \text{ ms}$**（系统吞吐率达 **$17,922 \text{ FPS}$**）；
- **峰值内存占用 (RSS)**：严格锁定在 **$1363.9 \text{ MB}$**（300 步连续推演中无 1KB 泄漏，实证确立常数 $O(1)$ 内存特性）。

## 五、 对抗导师 / 评委质疑的“防御问答”（Q&A Defense）

### Q1：为什么不用更强更火的长上下文因果 Transformer 做基准？你是不是把基准选弱了？
**回答策略**：
我们直接构建了包含因果多头注意力和 16 步滑动 KV-Cache 的标准因果 Transformer 世界模型，并在 200 帧真实视频上进行了同台对标。实测证明：
1. **显存物理壁垒**：Transformer 依赖缓存历史 Token，显存随时间步线性膨胀 $O(T)$，无法在边缘端持续运行；
2. **长程自回归自吞噬发散**：在开环推演中，Transformer 必须将自己前一步生成的预测 Token 塞回 KV-Cache，微小误差在第 5 步即开始指数级雪崩（累积误差达 $22,363$）；而 TTT 已经将物理知识固化进权重矩阵自身，开环推演无需历史缓存，累积误差稳定在 $0.033$（相对降低 100%）。

### Q2：你所做的“测试期训练”跟“在线微调（Online Fine-Tuning）”有什么本质区别？
**回答策略**：
我们在实验中专门加入了“开放动力学核心所有权重进行在线 SGD 微调”的消融组：
1. **精度优势**：在 150 帧在线流式跟踪中，In-Weights TTT 的单步误差（$0.0016$）比全网在线微调（$0.0045$）**精度高出 2.78 倍**。因为全网微调缺乏正交约束，深层多层网络在单样本频繁梯度冲击下会积累随机游走噪声并破坏全局流形；
2. **算力与显存优势**：全网微调必须在推理期为深层网络维护反向求导计算图（Autograd Graph）；而 TTT 仅对小尺寸矩阵 $W_t$ 进行闭式代数投影乘法（$\Delta W = -\eta P_\perp x_t e_t^\top$），边缘芯片计算开销仅为全网微调的 $\frac{1}{3} \sim \frac{1}{5}$。

### Q3：为什么参数矩阵内部不用矩阵级卡尔曼滤波，而是把贝叶斯放在外环？
**回答策略**：
我们实测推导了矩阵级卡尔曼滤波（RLS-Kalman）：
- 深度网络提取的上下文特征 $x_t$ 具有极强的**低秩共线性**，黎卡提更新会导致参数协方差矩阵的条件数暴增并引发数值发散；
- 因此，最优的工程拓扑是**“内环一阶欧氏正交流（保持简单、极低计算量与绝对数值稳定）+ 外环逻辑贝叶斯门控（利用动能衰减门控消除开环推演过补偿）”**。
